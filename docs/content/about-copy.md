# about the abstract room

The About section (the You tab, the landing page, and the store listing) uses this text. The app shows it in lowercase to match the brand; the original capitalisation is kept here.

## text

The Abstract Room is an experiences and media company for India's most passionate pop-culture lovers.

Since 2020, we've built an 80,000+ community, hosting 700+ events across seven cities with 9,000+ participants from 15+ countries. Through VIP, we're taking it to the world, helping people belong through the art they love.
